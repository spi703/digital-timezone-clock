# Setup GitHub Pages

## Automatic Setup (Recommended)

1. Go to: https://github.com/spi703/digital-timezone-clock/settings
2. Scroll down to "GitHub Pages" section
3. Under "Source", select "Deploy from a branch"
4. Select branch: **main**
5. Select folder: **/ (root)**
6. Click "Save"
7. Wait 1-2 minutes for deployment

## Access Your App

Once deployed, your app will be available at:
```
https://spi703.github.io/digital-timezone-clock/
```

## Live Demo

- Click any quick-add button to instantly add a popular timezone
- Watch the clocks update in real-time
- Add multiple timezones to compare times
- Perfectly responsive on mobile devices

## Troubleshooting

- If pages don't show up immediately, wait 2-3 minutes
- Clear your browser cache (Ctrl+Shift+Delete)
- Check the "Actions" tab to see deployment status
- Ensure index.html exists in the root directory

## Custom Domain (Optional)

You can add a custom domain in the GitHub Pages settings if desired.
